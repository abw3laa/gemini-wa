# gemini-wa

بوت WhatsApp شخصي مبني على Gemini API الرسمي (مش Web session — راجع
[لماذا](#ليش-api-الرسمي-وليس-جلسة-الويب) بالأسفل). البوت بيرد على رسائلك
تلقائيًا، بيتذكر سياق المحادثة، وبتقدر "تعلّمه" معلومات ثابتة (أسعار،
سياسات، أسئلة شائعة) يرجعلها عند الحاجة.

## البنية العامة

```
مستخدم WhatsApp
      ↓
whatsapp-service (Node.js + Baileys)
      ↓  HTTP (X-API-Key)
gemini-wa (Python + FastAPI)
      ↓
Gemini API الرسمي (Google)
```

مشروعين منفصلين تمامًا، بيتواصلوا عبر HTTP فقط:

| المجلد | المسؤولية | اللغة |
|---|---|---|
| `gemini-wa/` | الاتصال بـ Gemini، حماية API، Rate Limiting | Python (FastAPI) |
| `whatsapp-service/` | الاتصال بـ WhatsApp، كل منطق البوت (ذاكرة، قاعدة معرفة، فلترة، أوامر إدارية) | Node.js (Baileys) |

---

## المتطلبات

- **Python 3.12+**
- **Node.js 20+** (جُرّب على v24)
- **مفتاح Gemini API** مجاني من [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
- حساب WhatsApp شخصي (للربط)

## التثبيت والتشغيل (المرة الأولى)

### 1. طبقة Gemini API

```powershell
cd gemini-wa
python -m venv venv
venv\Scripts\Activate.ps1        # على Windows PowerShell
# source venv/bin/activate       # على macOS/Linux

python -m pip install -r requirements.txt
copy .env.example .env           # أو cp على macOS/Linux
```

افتح `.env` وعبّي:
```
GEMINI_API_KEY=<مفتاحك من AI Studio>
API_KEY=<اخترع مفتاح داخلي - مثلاً بأمر: python -c "import secrets; print(secrets.token_hex(32))">
```

شغّل (خليه شغال بترمنال منفصل طول الوقت):
```powershell
uvicorn app.api.app:app --reload
```

اختبار سريع (بترمنال ثاني):
```powershell
python main.py
```
لازم يرجعلك رد حقيقي من Gemini.

### 2. طبقة WhatsApp

بترمنال جديد:
```powershell
cd whatsapp-service
npm install
copy .env.example .env
```

افتح `.env` وعبّي **على الأقل**:
```
GEMINI_API_INTERNAL_KEY=<نفس قيمة API_KEY من الخطوة السابقة بالضبط>
WHATSAPP_LINK_METHOD=qr
```

شغّل:
```powershell
npm start
```

امسح كود QR اللي رح يظهر بالترمنال من هاتفك:
**WhatsApp → الإعدادات → الأجهزة المرتبطة → ربط جهاز**

### 3. حدد نفسك كمدير (خطوة ضرورية)

بدون هاي الخطوة، أوامر الإدارة (`/train`, `/status`...) ما رح تشتغل حتى لإنت:

1. من رقم WhatsApp تاني، أرسل أي رسالة خاصة للبوت
2. بالترمنال تبع `whatsapp-service`، رح تشوف سطر:
   ```
   📩 من [شي زي: 9639xxxxxxxxx@s.whatsapp.net]: ...
   ```
3. انسخ القيمة كاملة، وحطها بـ `.env` تبع `whatsapp-service`:
   ```
   ADMIN_JIDS=9639xxxxxxxxx@s.whatsapp.net
   ```
4. أعد تشغيل `npm start`

## وين أعلّم البوت كيف يرد؟ 🎓

هون بالضبط — أمر `/train`، خاص، من رقمك (المحدد بـ `ADMIN_JIDS` فوق):

```
أنت: /train
البوت: تفضل، أرسل المعلومة بصيغة:
       السؤال أو الموضوع | الجواب المطلوب
أنت: شو سعر تصميم الموقع؟ | يبدأ من 50$ حسب المتطلبات
البوت: تم الحفظ ✅
```

أو بخطوة وحدة مباشرة:
```
/train شو سعر تصميم الموقع؟ | يبدأ من 50$
```

**كيف بتصير مفيدة فعليًا:** بعد كده، أي شخص (مو بس إنت) يسأل بصيغة قريبة
("كم بتكلف تصميم موقع؟"، "بدي أعرف سعر الموقع") — البوت بيدور تلقائيًا
بقاعدة المعرفة، يلاقي المعلومة المرتبطة، ويستخدمها بالرد. هذا يصير قبل
كل رسالة تلقائيًا، ما تحتاج تسوي أي شي إضافي بعد ما تضيف المعلومة.

**أوامر إدارة قاعدة المعرفة الكاملة:**
```
/train                          - وضع تفاعلي (يسألك خطوة بخطوة)
/train <سؤال> | <جواب>          - إضافة مباشرة
/knowledge                      - عرض كل المعلومات المحفوظة
/knowledge remove <id>          - حذف معلومة معينة
```

كل هاي الأوامر محصورة برقمك (`ADMIN_JIDS`) — أي حد تاني يجرب يستخدمها
بيرجعله رد "هذا الأمر متاح للإدارة فقط 🔒".

> 💡 **ملاحظة**: القاعدة تُخزّن بملف `whatsapp-service/data/knowledge.json`
> (يُنشأ تلقائيًا)، وتبقى محفوظة بعد إعادة التشغيل - بعكس ذاكرة المحادثة
> العادية اللي تُصفّر عمدًا.

## أوامر الإدارة (خاص فقط، رقمك المحدد بـ ADMIN_JIDS)

| الأمر | الوظيفة |
|---|---|
| `/help` | قائمة كل الأوامر |
| `/status` | حالة البوت (مدة التشغيل، عدد المحادثات، إلخ) |
| `/train` | إضافة معلومة لقاعدة المعرفة |
| `/knowledge` | عرض/حذف معلومات قاعدة المعرفة |
| `/settings` | عرض الإعدادات الحالية |
| `/groups` | عرض إعدادات المجموعات |
| `/cancel` | إلغاء عملية `/train` جارية |

## الميزات (ملخص)

- ✅ رد تلقائي بالنص عبر Gemini (يحدد التاريخ/الوقت الحقيقي تلقائيًا)
- ✅ فهم الصور (ترسل صورة، البوت يوصفها/يجاوب عليها)
- ✅ ذاكرة محادثة قصيرة المدى (يتذكر آخر ~20 رسالة بكل محادثة)
- ✅ قاعدة معرفة دائمة قابلة للتعليم (`/train`)
- ✅ تجميع الرسائل المتتالية بطلب واحد (Debounce) بدل استهلاك حصة الحد
  المجاني على كل رسالة لحالها
- ✅ حماية من تجاوز حد الطلبات بالدقيقة (RPM) - ينتظر بذكاء بدل ما يفشل
- ✅ دعم مجموعات WhatsApp (اختياري، معطّل افتراضيًا) مع تفعيل عبر mention
  أو بادئة أمر
- ✅ تجاهل الرسائل القديمة المعلّقة (backlog) عند إعادة الاتصال
- ✅ أوامر إدارية محمية برقم محدد فقط
- ✅ جاهز للرفع على Render أو Oracle Cloud (`DEPLOYMENT.md` /
  `ORACLE_DEPLOYMENT.md`)

## قيود معروفة (بوعي، مو أخطاء)

- **الحد اليومي لطلبات Gemini غير متتبَّع حاليًا** (بس حد الدقيقة
  محمي) - لو استهلكت الحد المجاني اليومي بالكامل، رح تحصل خطأ من Gemini
  حتى لو ما تجاوزت حد الدقيقة
- **ذاكرة المحادثة تُصفّر عند إعادة تشغيل السيرفر** (مقصود - تصميم بسيط،
  بعكس قاعدة المعرفة اللي تبقى محفوظة)
- **بحث قاعدة المعرفة بالكلمات المفتاحية** مو embeddings حقيقية - كافٍ
  لقاعدة معرفة شخصية بعشرات/مئات المدخلات
- **دعم الوسائط محصور بالصور فقط** حاليًا (صوت، فيديو، PDF غير مدعومين بعد)

## استكشاف الأخطاء الشائعة

| المشكلة | الحل |
|---|---|
| `ModuleNotFoundError: No module named 'dotenv'` | تأكد الـ venv مفعّل (`venv\Scripts\Activate.ps1`) قبل `pip install` |
| `متغير البيئة 'GEMINI_API_KEY' غير موجود` | تأكد عبّيت `.env` مو `.env.example`، وبدون مسافات حوالين `=` |
| `404 NOT_FOUND` على اسم موديل | الموديل تقاعد - حدّث `GEMINI_MODEL` بـ `.env` لأحدث إصدار متاح |
| رد بطيء جدًا / خطأ 429 | تجاوزت حد الطلبات (RPM أو اليومي) - انتظر شوي أو راجع حصتك بـ AI Studio |
| البوت يرد على أسئلة قديمة غريبة | تجاهل - آلية "تجاهل الرسائل القديمة" (backlog) موجودة تلقائيًا من Phase 7 |
| أوامر `/train` `/status` ما بتشتغل | تأكد ضبطت `ADMIN_JIDS` بالضبط (JID، مو رقم الهاتف العادي) وأعدت التشغيل |

## الأمان

- **لا يوجد أي secret بالكود** - كل شي عبر `.env` (محمي تلقائيًا بـ
  `.gitignore`، ما يترفع على GitHub أبدًا)
- **مفتاحين منفصلين تمامًا**: `GEMINI_API_KEY` (لجوجل) و`API_KEY`
  الداخلي (يحمي API الخاص فينا من أي استخدام غير مصرح - خصوصًا مهم
  بعد الرفع على سيرفر عام)
- **الأوامر الإدارية محصورة** بـ `ADMIN_JIDS` فقط
- **مجلد جلسة WhatsApp** (`auth_info_baileys/`) و**قاعدة المعرفة**
  (`data/`) محميين بـ `.gitignore` - يحتويان بيانات حساسة/شخصية

## ليش API الرسمي وليس جلسة الويب؟

خيار مقصود من بداية المشروع: استخدام جلسة متصفح Gemini الشخصية (بدل
API الرسمي) يخالف شروط استخدام Google، ويعرّض الحساب الشخصي بالكامل
(Gmail، Drive...) لخطر حظر أو تعليق - خصوصًا لو شغّلته من سيرفر سحابي
(IP مختلف عن نمط استخدامك الطبيعي). الـ API الرسمي أبطأ شوي بالإعداد
الأولي (تحتاج تدير حدود الاستخدام المجاني)، لكن مستقر، موثّق، وآمن على
حسابك الشخصي بالكامل.
